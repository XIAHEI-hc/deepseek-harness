# @deepseek-ai/dsh-client-ui-skill-plaza

[English](README.md) | 中文

## 概述

本插件为 Web 客户端提供技能广场：侧栏入口把已发布技能浏览成流程缩略图卡片，并把某个精确版本打开成单页文档——结果示例、可交互流程、适用场景与已存储正文——同时允许在发布前编辑草稿。它还提供完成回复上的「生成 Skill」操作，以及把已发布技能的原生 `/name` 手势写入草稿的输入框选择器。所有读写都经由 `skillPlaza` Remote，插件本身不持有广场状态；没有结构化流程的版本仍会按执行步骤成图。

<a id="use-this-package"></a>
## 使用本包

把该行挂载到 Web profile 的浏览器端清单：

```yaml
- id: ui-skill-plaza
  name: '@deepseek-ai/dsh-client-ui-skill-plaza'
```

插件依赖 `conversation`、`layout`、`locale`、`remote.skillPlaza`、`sessions`、`slots` 与 `uiWorkspace` 服务，并需要在 Host 上挂载 `@deepseek-ai/dsh-skill-plaza`。

### 界面位置

| 界面 | 插槽 | 作用 |
|---|---|---|
| 侧栏入口与页面 | `sidebar.panellist`、`main` | 以流程缩略图浏览目录、把某个已发布版本打开成单页文档、编辑并预览草稿、发布版本 |
| 生成入口 | `conversation.chat.assistant-actions` | 启动该回复所属轮次的生成，之后显示为进行中、已生成或可重试 |
| 生成任务卡 | `conversation.chat.turnTail` | 画进行中的尝试——阶段清单、已产生字数、用时、取消——以及它产出的草稿，并给出唯一一个打开它的操作 |
| 技能选择器 | `conversation.input.left` | 列出已发布技能，按名称、标题或用途筛选，并把 `/name ` 写入草稿 |

一次生成是一个任务，而不是一次请求。入口启动它，卡片跟随 Host 的尝试记录直到落定，广场只在用户要求打开草稿时才进入：生成完成不会把对话替换成另一个页面。尝试运行期间重复点击会加入它，失败或已取消之后点击会运行同一任务的下一次尝试。

两个入口读同一个按会话划分的生成状态存储，以收尾消息标识为键，因此回复所属的轮次与它的卡片不会对尝试的进度给出不同答案。

草稿编辑会带上渲染时的修订号，因此另一个窗口的保存会表现为冲突，并保留本地内容供复制，而不是静默覆盖。

### 页面与状态

页面所属的工作区，取当前挂载了会话界面的那个会话；没有挂载会话时指向 Host 默认目录。工作区变化会整体重挂视图，这样某个工作区的详情页、已加载图片与进行中的读取不会渗到另一个工作区。

「在对话中使用」会钉住详情页当前显示的版本，只有钉住成功后才插入调用指令；输入框已有内容保留，且不会自动发送。当前没有会话时，它走平台已有的新建会话入口创建会话，再插入。

## Model Experience

本插件不产生模型输入：它只把原生 /name 文本写入未发送的草稿，并读取 Host 的广场 Remote。

#### KV 缓存影响

无；发布正文由 `@deepseek-ai/dsh-skill-plaza` 提供方提供，缓存影响归它所有。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- **选择器插入的是文本，不是绑定引用** — 选中的技能变成原生 `/name` 文本，因此 Host 会注入下一步钉住的版本，没有钉住时注入当前版本。广场自身的页面总是在插入前先钉住。
- **卡片缩略图跟随目录数据，而不是完整流程图** — 每张卡片只画活动版本根层的节点标签与判断数；嵌套层与连线的具体结构只在详情页展示。
- **技能包展示的是已存储内容，不是文件** — 广场技能存放在广场的存储域里，因此该节渲染已存储的模型可见正文及其示例与工具，没有目录清单或压缩包导出。
- **流程编辑器是表单式的** — 节点与带标签的连线通过表单列表增删改，没有拖拽式画布编辑；编辑器仍使用独立预览，而不是实时预览。
- **每张示例图一次上传** — 节点引用草稿里已上传的某张示例图，而不是自己独立的上传控件。
- **生成任务生活在本客户端** — 卡片镜像 Host 的尝试记录，但「某个轮次对应哪次尝试」是浏览器状态。重载之后卡片消失；它产出的草稿仍在广场里，再次启动生成会加入 Host 上仍在运行的那次尝试。
- **进行中的卡片报告的是进度，不是草稿** — 它显示 Host 到达的阶段与模型已产生的字数，草稿字段在尝试落定后才出现。要边生成边显示字段，需要 Host 目前不发布的局部内容契约。
- **页面读取已挂载会话的工作区** — 在没有打开会话时进入广场，指向 Host 默认目录，而不是用户挑选的某个工作区。
